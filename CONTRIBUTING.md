# Contributing

We are temporarily pausing unsolicited pull requests while the maintainers focus on AiiDA v3.
The codebase is undergoing substantial refactoring, and our review capacity is reserved for this work.
New and existing unsolicited pull requests will be closed during this period.

Bug reports and design discussions remain welcome on [GitHub issues](https://github.com/aiidateam/aiida-core/issues) and [Discourse](https://aiida.discourse.group/).
